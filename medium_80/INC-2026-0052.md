## Symptom
The platform infrastructure team noticed a significant increase in feature flag evaluation latency spikes during peak hours. This symptom was first observed through monitoring alerts, which indicated that the average latency had exceeded the threshold of 500ms. Further investigation revealed that this issue was affecting multiple services, causing delays in processing requests.

Upon closer inspection, it became apparent that the latency spikes were correlated with a high volume of incoming messages to the shared message broker. The team suspected that the broker might be overwhelmed, leading to a backlog of messages and subsequent delays in processing.

The symptom complex was characterized by intermittent spikes in latency, followed by brief periods of normal operation. This pattern suggested that the issue was related to the message broker's ability to handle a high volume of messages, rather than a persistent fault in the underlying infrastructure.

## Diagnosis steps and hypotheses
Initial hypotheses centered around a potential misconfiguration of the message broker or an issue with the underlying network connectivity. To investigate, the team used the `broker-admin` tool to inspect the broker's state and configuration. A key command used in this process was:
```
broker-admin show-connections
```
This revealed an unusually high number of active connections, suggesting that the broker might be overwhelmed. However, further analysis was needed to determine the root cause of this condition.

## Resolution steps
1. Restart broker with --max-connections 500
2. Set registry_gc_interval to 30m in /etc/broker/config
3. Run registry-gc with --dry-run to test
4. Increase log level to DEBUG in /var/log/runner-logs

## Post-mortem note
The shared message broker exceeded its connection limit due to a misconfigured registry gc interval. This incident highlighted the importance of regularly reviewing configuration settings for critical infrastructure components like the message broker, to prevent similar issues from arising in the future.
