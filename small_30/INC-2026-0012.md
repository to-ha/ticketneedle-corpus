## Symptom
The incident began with reports of JWT signature validation failures for a subset of tokens. Users attempting to access protected resources were met with authentication errors, despite having valid credentials. This symptom was first observed by monitoring tools and later confirmed by user reports. The failure rate was not uniform across all users, suggesting an issue with the directory replication process.

Further investigation revealed that the affected users were those whose authentication data had been updated recently. This pattern hinted at a problem with how changes were being propagated across the directory service. Given the critical nature of authentication, even a partial failure can have significant impacts on service availability and user trust.

As the incident unfolded, it became clear that the issue was not with the tokens themselves but with how the authentication system was verifying them against the directory service. The inconsistent failure rate among users pointed towards an infrastructure or configuration problem rather than a software bug in the authentication mechanism.

## Diagnosis steps and hypotheses
Initial hypotheses included network connectivity issues and firewall misconfigurations. However, upon further investigation, these were ruled out. The team then turned its attention to the directory service itself, suspecting issues with replication. A key diagnostic step involved testing ldap connectivity:
```
ldapsearch -x -H ldap://node1:389 -D cn=admin -w password
```
This test helped confirm that the directory service was accessible but did not immediately reveal the replication issue. Further analysis of replication logs and settings was necessary to uncover the root cause.

## Resolution steps
1. Restart directory service on node 1
2. Set replication interval to 300 seconds
3. Verify ldapsearch connectivity to node 2 on port 389
4. Run pam-test with debug flag to check auth flow

## Post-mortem note
Directory replication failed due to incorrect configuration. This incident highlights the importance of regularly reviewing and testing directory service configurations to prevent such failures. The swift escalation and collaborative effort among teams were crucial in resolving the issue before it could impact a larger user base.
