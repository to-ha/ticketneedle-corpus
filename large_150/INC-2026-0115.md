# Major Incident — INC-2026-0115
* **Ticket ID:** INC-2026-0115

* **Status:** Resolved

## Symptom
The network team observed asymmetric routing after a recent configuration push. This resulted in packets taking a different path than expected, leading to increased latency and packet loss. The issue was first noticed by monitoring tools, which alerted on abnormal routing patterns.

Further investigation revealed that the asymmetric routing was causing issues with traffic flowing between data centers. The anycast VIP, which is used for load balancing and routing, seemed to be the focal point of the problem. 

Initial observations suggested a possible misconfiguration or issue with the BGP timers, but this needed further exploration.

## Escalation timeline
* 07:12 — L1 Network operations: Ines - She began by reviewing the configuration changes made prior to the incident and checking for any errors or inconsistencies.
* 07:52 — L2 Network engineer: Mei - Mei took over the investigation, focusing on the BGP settings and anycast VIP configurations to identify potential causes of the asymmetric routing.

## Diagnosis steps and hypotheses
To diagnose the issue, the team considered several hypotheses, including a misconfigured BGP timer or an incorrect anycast VIP setup. They attempted to verify route propagation using various tools like `dig` and `traceroute`. A key command used in the diagnosis was:
```
dig +trace 192.168.1.100
```
This helped in understanding how the routes were being propagated and where the issue might be occurring.

## Resolution steps
1. Restart router with ID 123
2. Set BGP timer to 30 seconds
3. Update anycast VIP to 192.168.1.100
4. Verify route propagation with dig +trace

## Post-mortem note
The anycast VIP route was not properly propagated due to a BGP timer misconfiguration. This incident highlights the importance of carefully reviewing configuration changes and ensuring that all settings, especially those related to routing and load balancing, are correctly implemented to prevent such issues in the future.
